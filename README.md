# security-app-practice

## 概要
COACHTECH 教材 Tutorial 10-6「Webセキュリティ ハンズオン」で作成した成果物です。

## 使用技術
- PHP 8.x
- Laravel 10.x
- CSRF 保護（`@csrf`）、XSS 対策（Blade の自動エスケープ）

## 学んだこと
- お問い合わせフォームが表示して、フォームに名前、メールアドレス、メッセージを入力して送信できるようにする
- CSRF保護が有効にさせる
- XSS対策が施させる

## 動作確認
ブラウザで確認。ソースで表示を確認後、@csrfを削除して動作を確認。確認後@csrfを追加。XSS対策の動作確認をソースで確認。

## 手こづったこと
確認後@csrfを戻しても413エラーが出て直らなかったが、新しく立ち上げたら直った。
